# noevoe - learn hobby

noevoe is a hobby learning app built using Expo React Native. It uses AI to prepare small lessons to help you achieve capabalities on the hobby you wish to learn (and enjoy :p). You can choose how far you want to go to enjoy the hobby, it will prepare the lessons accordingly. It is based on the philosophy that "Hobbies are meant to be enjoyed".

## Flow
- You describe the hobby you want to learn, how much you know it already (it's okay to be a beginner too), and how far do you want to go
- The app prepares 5-8 capabilities you can achive by following the path created (so you enjoy the path as much as the target)
- Each capability has small lessons with tips and quizzes to help you learn
- All your paths and lessons are stored locally on your phone

---

### 1. Tech-stack
The app is built using Expo React Native with TypeScript. All the data is stored locally on the end device.

#### Installation:
1. Clone the repository and navigate to the `noevoe-app` directory
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npx expo start
   ```
4. Install Expo Go app on your smartphone and scan the QR shown in your terminal to run in development environment
